# Beat the Legendary

A small browser game: assign hidden base stats to random Pokémon and try to out-score a legendary's base stat total (Arceus 720, Mewtwo 680, Deoxys 600).

- **Classic** (Easy / Hard): give each of six Pokémon one stat.
- **Modern**: each round, lock in one stat + Pokémon pair; the rest are re-dealt.
- Powerups (once a day each): **Reroll** and **Reveal**.

Every game is guaranteed winnable. Static site, no build step — open `index.html` or serve with GitHub Pages.
